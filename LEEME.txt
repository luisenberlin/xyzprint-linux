xyzprint-cli — reconstruccion del port Linux de XYZprint (da Vinci 1.0 Pro)
=========================================================================

Contenido minimo para compilar. La estructura de directorios NO se debe
cambiar: src/CMakeLists.txt instala el perfil desde ../profiles y los tests
localizan la raiz con ../../.

Dependencias (Debian/Ubuntu)
----------------------------
  sudo apt update
  sudo apt install build-essential cmake ninja-build \
      qt6-base-dev qt6-serialport-dev libssl-dev

  # solo para el subcomando "slice":
  sudo apt install cura-engine

Compilar y probar
-----------------
  node tools/check-profile.mjs          # valida el perfil sin Qt
  cmake -S src -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
  cmake --build build
  ctest --test-dir build --output-on-failure

Uso
---
  ./build/xyzprint-cli ports
  ./build/xyzprint-cli status --port /dev/ttyACM0
  ./build/xyzprint-cli slice modelo.stl modelo.3w --keep-gcode modelo.gcode
  ./build/xyzprint-cli send modelo.gcode --yes
  ./build/xyzprint-cli wrap modelo.gcode modelo.3w
  ./build/xyzprint-cli inspect modelo.3w

  # sube y ARRANCA la impresion; exige --yes
  ./build/xyzprint-cli upload modelo.3w --port /dev/ttyACM0 --yes

  # atajo instalado en ~/.local/bin: empaqueta + imprime en un paso
  ./tools/install-local.sh && xyzsend modelo.gcode

Permisos del dispositivo
------------------------
  sudo install -m 0644 packaging/udev/99-xyzprinting.rules /etc/udev/rules.d/
  sudo udevadm control --reload-rules && sudo udevadm trigger

fuente de XYZprinting. No se redistribuyen binarios ni DLL del fabricante.
